# 测试复盘

## 当前证据

个人本地原型完成Dify服务API与网页点击端到端运行。公开样本是三次运行的缩减回放，聚合指标见`examples/results-summary.json`。不是性能基准、随机抽样或完整标注集。

| 场景 | 观察到的问题 | 产品意义 |
|---|---|---|
| 内部问答工具选型 | n8n定价缺失；草稿合并引用了Tracing和Last run | 不完整研究要保留缺口，复核需到主张级 |
| 耳机 | 旧兼容列表的模型解释被表述为官方声明 | 条件字段也可能是模型推断，字符串校验不够 |
| Venchi | 商品读取不全、SKU未确认；模型仍PASS | 研究充分性必须独立于报告一致性 |

本轮公开准备再次执行后端6项集成测试与JS语法检查；检查的是接口与状态行为，不是研究准确率。完整工作流早期有143条本地结构/引用/边界断言，但本仓库未移植该验证器，不能将其当作本仓库当前CI结果。

## 不应被忽略的失败

部分成功意味着部分采集节点失败后流程继续，并不等于完整研究成功。读到官网不等于已验证所有主张；同模型复核也可能漏错。已有助手修订报告不是原始模型自动输出，不能混为一次模型成功。

## 建议的下一轮评测（尚未完成）

固定覆盖：型号模糊、错版本、历史价、不同单位、缺来源、网页失败、正文截断、足够资料、来源相互矛盾。每个样本先定义应获取字段与不可推断内容，再由两人标注关键主张是否被证据支持。报告分开统计采集成功、证据覆盖、语义支持、未知处理与需求充分性，避免只用一个总分。
