# Demo：用3分钟证明你做了什么

## 交付形态

当前是可运行本地Web原型，不是公网SaaS。GitHub展示源码与文档；现场演示用本机面板；短视频作为异步介绍。公开视频和公网体验链接尚未制作/部署，不要在简历写“已上线”。

## 3分钟录屏脚本

| 时间 | 操作 | 讲述重点 |
|---|---|---|
| 0:00–0:25 | 展示任务表单 | 谁在什么场景下比较什么；固定型号与4个维度 |
| 0:25–0:55 | 切换到事先完成的真实运行 | 标注“真实运行回放”，不要装成实时完成；解释步骤与异常 |
| 0:55–1:35 | 点击网页读取与一个来源 | 看网址、获取时间、截断状态和原文；引用存在不代表结论正确 |
| 1:35–2:15 | 打开结论复核 | 展示耳机案例如何把模型解释当官方声明，为什么拦截 |
| 2:15–2:45 | 保存人工意见，展示版本对比 | 机器状态和人工意见独立，历史不被覆盖 |
| 2:45–3:00 | 总结限制 | 采集不全、同模型偏差、下一步人工标注；不虚报收益 |

录屏建议用系统录屏工具，浏览器单独窗口，关闭通知，不展示设置里的密钥或个人订单。录制前导入公开examples的缩减回放；它不含完整事实和正文，因此完整证据演示应使用本机实际记录，并逐项确认不含私人信息。

## 无密钥演示

1. 在`panel`运行`start.ps1`，打开`http://127.0.0.1:8765/`。
2. “导入结果”选择/粘贴`examples/case-2.json`。
3. 查看步骤、报告与质量检查，说明这是公开脱敏摘要，不是本轮实时运行。
4. 不点击实时执行；无需配置任何API。

## 实时演示

先完成[连接配置](setup.md)。新建相同耳机任务，说明本次会消耗外部额度，点击“研究计划→输出→发起研究运行”。预计等待时间不承诺固定值；上次约218秒只是一次观察。过程失败也展示真实状态，不重复点击以免多次消耗。录屏可分段，但应标注省略等待，不能剪成虚假的秒级完成。

## 现场备选案例

- 软件选型：展示计费口径不能直接等同、Tracing引用复核。
- 耳机：展示具体型号、历史价格不能冒充当前价。
- 食品：展示SKU和商家网页读取边界，证明系统知道何时不推荐。

最有说服力的是“发现问题并解释产品取舍”，不是把所有灯改成绿色。
